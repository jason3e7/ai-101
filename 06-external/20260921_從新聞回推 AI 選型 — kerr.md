# 從新聞回推 AI 選型 — Inferring Model Choice from Public Timeline

[← 回主頁](../index.md)

> [!NOTE]
> 原文: [kerr-notes: 從一則新聞, 回推十年前的 AI 選型](https://github.com/kerr20801/kerr-notes/blob/main/ai-systems/2026-09-11-inferring-ai-model-choice-from-timeline.md) (2026-09-11). 起因是 Moderna 癌症疫苗 (mRNA-4157/V940) 三期臨床達標, 結果聊出**一套可以套用到任何「某公司用 AI 做了 X」新聞的推理框架**. kerr 有標清楚: 這篇的價值是推理方法本身, 不是爆料 Moderna 用了什麼.

> **TL;DR (EN):** A framework for inferring which ML models an organization likely used, based only on public information. Applied to Moderna's Phase-3 mRNA cancer vaccine announcement (2026-08-19). Two filters compose. **Timeline**: the org stated "using ML for this >10 years" → cuts everything published after ~2016. **Problem shape**: peptide-MHC binding prediction is "fixed-length sequence → single score", which is not sequence labeling and not outlier detection. Applied to six candidates: CRF (shape wrong), ECOD (2022, wrong assumption), ANN/NetMHCpan (fits, 2016), Random Forest (fits, literature confirms), XGBoost (edge case, likely later iteration), LightGBM/CatBoost (too late). Inferred baseline: shallow ANN + Random Forest around 2015 to 2017, with mass-spec eluted-peptide data mixed in 2017 to 2020, deeper architectures by 2020+. Generalization: for any AI adoption story, "how long has this been going?" and "what shape is the task?" together narrow the model family to a handful of provable candidates.

---

## 兩條線一起卡 — The Two-Filter Framework

**線一: 時間軸.** Moderna/Merck 官方確認「用 ML 做這個超過 10 年」, 起點回推到 2015 到 2016. 任何 2016 年之後才發表的模型, 不可能出現在最初版本裡.

**線二: 問題形狀.** 這件事具體要解什麼?

1. 從腫瘤 DNA vs 正常 DNA 比對, 找出突變. **這步是確定性比對, 不需要 ML**
2. 判斷每段突變胜肽 (peptide) 跟病人 HLA 結合得好不好. 這步才是 ML 問題, 形狀是**輸入固定長度序列, 輸出一個結合分數**

第 2 步的形狀決定「哪些模型天生合適」. 時間軸砍太晚的, 問題形狀砍不合適的, **兩條都過才算合理候選**.

## 檢驗過的六個候選 — Six Candidates Checked

| 候選 | 時間 | 問題形狀 | 結論 |
|:---|:---|:---|:---|
| **CRF** (2001) | ✓ | ✗ 序列標記, 不是整段打分 | 淘汰 (形狀不合) |
| **ECOD** (2022) | ✗ 太晚 | ✗ 假設維度獨立, 但胺基酸互相影響 | 雙重淘汰 |
| **ANN / NetMHCpan-3.0** (2016-03) | ✓ 剛好卡在起點 | ✓ 整段輸入 → 一個輸出, 完美吻合 | **主力候選** |
| **Random Forest** (2001) | ✓ 早就成熟 | ✓ 有真實論文用 RF 做 Class I HLA 預測 | **有實證** |
| **XGBoost** (2014 工具 / 2016 論文) | ⚠️ 卡在邊界 | ✓ | 可能後期 (~2018-2020) 才加入 |
| **LightGBM** (2017), **CatBoost** (2018) | ✗ 都太晚 | — | 只可能出現在近期升級版 |

kerr 把幾條線索拼起來, 推論出的十年演進軌跡:

```
2015-2017 (起點)    淺層 ANN (NetMHCpan 系) + Random Forest
                    訓練資料: 實驗室量測的結合親和力
        │
        ▼
2017-2020 (迭代)   加入質譜「洗脫胜肽」資料
                    (真實從細胞表面量到的, 比體外結合更準)
                    XGBoost 可能被納入
        │
        ▼
2020-2026 (現版)   更深的架構 + 更大規模驗證
```

kerr 特別強調: **每一步都對應到一篇查得到的論文或發布年份**, 沒有一步是猜的.

## 為什麼這個框架好用 — Why This Works Beyond Biotech

任何一則「某公司用 AI 做到 XX」的新聞, 都可以問這兩題:

1. **這件事做了多久?** (回推時間軸, 砍掉太晚的模型)
2. **任務的輸入輸出形狀是什麼?** (序列標記 / 整段分類 / 異常偵測 / 生成 / ranking → 形狀決定家族)

實際套用場景:

- 「某銀行用 AI 做詐欺偵測 15 年」: 十五年前是 SVM / Logistic Regression / rule-based, deep learning 不太可能是骨幹, 頂多後期補上
- 「某電商用推薦系統 10 年」: 2016 年還沒 GNN, 大概率是 collaborative filtering + matrix factorization
- 「某新創用 LLM 做 X 兩年」: 2024 已經是 GPT-4 世代, 但 fine-tune 什麼 base、有沒有做 RAG, 從新創規模和發表節奏可以進一步縮

**兩條線都卡住之後, 候選模型通常剩三個以內**, 剩下就看有沒有具體論文或該公司之前發表的 blog 可以佐證.

> [!IMPORTANT]
> 這個框架的價值不是「猜對」, 是**把黑箱從無限可能收斂到少數幾個, 而且每個都有可查證的依據**. 黑箱不能完全拆, 但可以拆對地方.

## 我的重點 — Takeaways

- **時間軸是最省力的第一刀**: 一個公開年份就砍掉一半候選, 效率比逐一討論高得多
- **問題形狀是第二把刀**: 序列標記 / 整段分類 / 生成 / ranking / 異常偵測 是完全不同的家族, **形狀選錯就物理上不能做**
- **框架可以雙向用**: 反過來看新技術也一樣, 一個 2025 才火的架構不會出現在 2020 就開始跑的系統核心
- **「有標籤時沒理由選無監督方法」是常忽略的判別**: kerr 淘汰 ECOD 用了這條, 值得記
- **推理跟爆料要分清**: kerr 全文有標「這是推論不是內幕」, 保留自己的可信度. 寫這類分析的態度值得學
