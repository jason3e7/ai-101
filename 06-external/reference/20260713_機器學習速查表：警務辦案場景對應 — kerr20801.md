## 這是什麼 — What It Is

大部分人記不住「這麼多演算法，什麼時候用哪個」。這篇用一個統一的比喻——**警局辦案**——把演算法對應到具體場景，變得好記。八大類：

| 類別 | 代表演算法 | 辦案場景比喻 |
|---|---|---|
| **迴歸**（預測數值） | 線性/多項式/Ridge/Lasso | 預測刑期、贓款金額、逃跑距離 |
| **分類** | 邏輯迴歸、隨機森林、XGBoost、SVM、貝氏 | 有罪/無罪判定、犯人分類 |
| **非監督分群** | K-Means、DBSCAN | 行為模式分組、犯罪熱點 |
| **降維** | PCA、t-SNE/UMAP | 案情簡報、視覺化 |
| **深度學習** | CNN、LSTM、Transformer | 影像辨識、時序、全局分析 |
| **異常檢測** | z-score、孤立森林、ECOD | 揪出反常行為 |
| **進階樹模型** | CatBoost | 處理類別型特徵 |
| **時間序列** | Prophet、HMM、CRF | 趨勢與序列預測 |

沒有程式碼，只有演算法名稱與數學概念（例如「3 個標準差」、One-Hot Encoding）。

## 值得記的原因 — Why It's Useful

它本質是一張**選型速查表**：拿到問題先問「這是預測數值、分類、分群、還是找異常？」，就能快速縮小到對的演算法家族。警務場景只是好記的外衣，換成任何領域都適用。
