# Usage-Based AI 時代開發新典範

> [!info]
> 原文：[Usage-Based AI 時代開發新典範](https://www.youtube.com/watch?v=WktaQ6r2qDw)
> **一句話：** Microsoft Taiwan 在 GitHub Copilot 切換 Usage-Based 計費（2026-06-01 生效）前發布的說明影片，涵蓋預算控管、Prompt / Context 優化、Token Optimization 等最佳實踐。

---

## 主要內容

配合 GitHub Copilot 於 2026 年 6 月 1 日正式切換 Usage-Based 計費模式，本影片提供開發團隊的應對策略：

- **計費模式解析**：新的 Usage-Based 計費如何計算 token 用量與費用
- **預算與用量控管**：如何設定上限、追蹤團隊用量
- **Prompt 與 Context 優化**：減少不必要的 token 消耗
- **Token Optimization**：維持開發效率的同時降低成本
- **實務案例**：可落地的設定建議

---

## 背景

GitHub Copilot 於 2026 年 6 月 1 日起切換為 Usage-Based 計費，以 GitHub AI Credits（基於 token 消耗）取代原有的 Premium Request Units（PRU）。各方案仍包含每月額度，超出後按用量計費。
