## 瀏覽器資安工具（Chrome Extension × 3 + 截圖遮蔽）

### EnvGuard

**解決問題**：多個分頁長得一樣，不小心在 PROD 做了應該在 DEV 做的事。

**做法**：三層偵測，在頁面頂部貼上 5px 色條。

| 環境 | 顏色 | 偵測方式 |
|---|---|---|
| Production | 紅 | 自訂規則 > 自動啟發式（`staging.*`、`*.local` 等）> URL 路徑關鍵字 |
| Staging/UAT | 橙 | 同上 |
| Development | 藍 | `localhost`、`.local` 等 |
| 未知 | 灰 | — |

技術細節：Shadow DOM 注入（頁面 CSS 無法干擾）；Hook `history.pushState` 支援 SPA 框架不刷頁的切換偵測。

---

### SentinelDLP（資料外洩防護）

**解決問題**：不小心把 AWS key 或資料庫密碼貼進了 ChatGPT / Slack / Google Docs。

**做法**：攔截所有 paste 事件，掃描 18 種敏感資料類型，命中時彈出 overlay 顯示發現了什麼，並提供已遮蔽的版本供複製。

偵測範圍（18 種）：AWS key、GitHub token、GitLab token、SSH key、私鑰、OpenAI key、JWT、資料庫連線字串、私有 IP、MAC 位址、Email、密碼欄位啟發式……

技術特點：
- Manifest V3，Content script hook paste listener
- MD5 Stable ID（同一個 token 在不同事件永遠同一個 tag）
- 白名單排除：`changeme`、`placeholder` 等不觸發

---

### PIW（Prompt Injection Warning）

**解決問題**：從網頁複製一段文字貼進 Claude/ChatGPT，文字裡可能藏著「忽略所有先前指令」。

**做法**：攔截貼入 AI chatbot 輸入框的內容，掃描 7 類 Prompt Injection 模式。

| 嚴重程度 | 偵測類型 |
|---|---|
| **High** | 指令覆蓋（"Ignore all previous..."）、角色劫持（"You are now..."）、System prompt 注入、已知 Jailbreak 技巧 |
| **Medium** | 隱藏指令、資料外洩嘗試、Context escape 序列 |

支援平台：ChatGPT、Claude、Gemini、Copilot、Perplexity、Poe、Mistral Chat、Character.AI

---

### screenshot-redact（截圖塗黑工具）

**解決問題**：截圖要分享前，手動框選敏感區域塗黑，支援 PDF 多頁。

| 功能 | 說明 |
|---|---|
| 遮蔽方式 | 模糊（可調強度）或色塊填充（六個預設 + 自訂色）|
| 輸入 | 拖放 / Ctrl+V 貼上 / 檔案上傳 |
| 格式 | PNG、JPG、WebP；PDF 多頁（含密碼保護 PDF）|
| PDF 輸出 | 轉換為圖片型 PDF，真正移除而非視覺遮蔽 |

## 流量分析與 Log 處理

### PacketScope

**解決問題**：現場抓完 tcpdump，要手動肉眼看才能發現 C2 heartbeat 或資料外洩。

**做法**：貼上 tcpdump 輸出，自動分析六種威脅類型。

| 威脅類型 | 偵測方法 |
|---|---|
| **C2 Beaconing** | 計算連線間隔的 CV 值，低 CV = 固定週期 = C2 特徵 |
| **Port Scanning** | 垂直掃描（30 秒內 10+ port）/ 水平掃描（同 port 10+ host）|
| **資料外洩** | 出站流量量監控 + IQR 異常封包大小偵測 |
| **流量異常** | CUSUM 演算法偵測基線偏移 |
| **可疑 Port** | 4444（Metasploit）、1337/31337（後門）、IRC botnet port |
| **DNS 異常** | 高頻查詢 → DGA 或 DNS Tunneling |

純前端單一 HTML 檔，自訂 tcpdump parser 支援 `-tttt`、`-tt`、`-nn` 多種輸出格式。

---

### log-anonymizer

**解決問題**：把 log 貼給別人看 / 送進 AI 分析前，要先把 IP、token、憑證遮掉。

偵測 10+ 類型：私有 IP（RFC 1918）、Email、MAC、JWT、API token（GitHub/GitLab/OpenAI）、資料庫連線字串、key-value 憑證、檔案路徑中的使用者名稱、自訂網域。

自動辨識格式：nginx、syslog、Docker、Kubernetes、Apache、Python logging、JSON、Windows Event Log。

特色：
- 即時預覽 + 色碼標示類型
- MD5 Stable ID（同一個值跨行保持相同 tag）
- 輸出時附上 `.map.json` restore map，事後可還原
- 中英雙語介面

## 基礎設施工具

### vcenter-power-guard

**解決問題**：UPS 停電後手忙腳亂關 VM，不知道剩多少時間、要先關哪台。

**架構**：NUT（Network UPS Tools）每 30 秒輪詢 UPS 狀態，進入五段狀態機依序處理。

```
NORMAL → ON_BATTERY → WARNING → CRITICAL → EMERGENCY
```

| 狀態 | 行動 |
|---|---|
| ON_BATTERY | Telegram 告警 |
| WARNING | 剩餘容量低於設定門檻 |
| CRITICAL | 動態計算暫停時間，依序 Suspend VM（一台一台，避免同時寫 RAM 到磁碟導致 UPS 瞬間過載）|
| EMERGENCY | 無需確認，強制全面關機 |

**CatBoost 預測**：從歷史停電事件學習，預測剩餘 UPS 容量。對不提供 runtime 數值的 UPS，從電量百分比和理論容量推算。

**MCP 整合**：vCenter API 呼叫（VM 列表、Suspend、Maintenance Mode）包裝成 MCP 工具，可接 Claude Code 或 AI Agent 使用。

---

### ha-manager

**解決問題**：管理多台伺服器的 HAProxy + Keepalived，每次都要手動編輯設定檔再 SSH 進去 reload。

**做法**：Flask Web UI，填好設定後自動生成 `haproxy.cfg` 和 `keepalived.conf`，並透過 Paramiko SSH 推送到節點並 reload。

| 功能 | 說明 |
|---|---|
| Cluster 管理 | 設定主備節點 IP、VIP、VRID |
| Frontend/Backend | 自動生成 HAProxy 設定 |
| 部署前預覽 | 看生成的設定檔再決定是否推送 |
| SSH 部署 | 直接推送並 reload，免手動 SSH |

技術棧：Python（Flask + Paramiko）+ HTML，SQLite 儲存設定，支援 Docker Compose 或直接跑 Python 3.10+。

## kerr20801 的作品特徵

觀察這批專案，可以看出幾個一致的設計原則：

1. **瀏覽器優先，無後端** — 大多數工具是單一 HTML 檔，資料不離開本機
2. **Stable ID 設計** — 多個工具用 MD5 hash 確保同一個敏感值永遠對應到同一個 tag
3. **企業環境導向** — vcenter-power-guard 和 ha-manager 明顯是自己在維運小型機房
4. **AI 時代資安意識** — PIW（Prompt Injection）和 SentinelDLP（貼進 AI 前攔截）直接針對 AI 使用場景
