# Opus 4.8 初體驗：黑話沒少、system prompt 感覺調過

> [!info]
> 原文：[shiham.wang Facebook](https://www.facebook.com/shiham.wang/posts/pfbid02oXbHfoyNA7MNKiN8B9Fnvac5TKEb2efiK4ptHB5A2RAnuXQoopf2BjtKDwVQwACel)
> **一句話：** 用了一個早上 Opus 4.8 的第一手感受：黑話沒有明顯減少、Token 燒速差不多，但 system prompt 感覺有調整——現在 Claude 會先說前提再行動，比如「這不能只靠記憶猜測，我會做實際探索」。

---

## 三點初步觀察

| 面向 | 觀察 |
|---|---|
| **黑話** | 沒有明顯變少，跟 Opus 4.7 差不多 |
| **聰明程度** | 目前沒有特別感覺，需要再觀察 |
| **Token 燒速** | 跟 Opus 4.6 差不多 |

---

## 最明顯的變化：行為模式調整

> [!tip] 值得注意的行為改變
> 感覺 system prompt 有調整：**現在 Claude 會更多地先說前提，再去行動。**

例子：
> 「這不能只靠記憶猜測，我會做實際探索」

這個模式代表 Claude 4.8 在不確定的時候會先聲明意圖再執行，而不是直接猜測——比較像是增加了自我覺察的層次。

---

## Anthropic 跟「7」有仇？

作者半開玩笑地觀察 Anthropic 的版本命名模式：

| 版本 | 評價 |
|---|---|
| Sonnet 3.7 | 「出來的時候一坨」 |
| Opus 4.7 | 被罵（甚至直接跳過 Sonnet 4.7）|
| **Opus 4.8** | 直接推出，顯示「有多急」|

> 「只能說 Anthropic 跟 7 好像有仇」

## 換圖了

> 「可以換圖了，同時繼續鼓勵 Claude 儘早改掉講黑話的壞習慣」

「黑話」在這個脈絡中指 Claude 傾向使用過於正式、AI 腔或企業用語的回應風格，是社群長期以來對 Claude 的批評之一。
