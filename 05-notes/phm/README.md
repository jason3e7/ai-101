## 送 flag 流程 — Flag Submission

PHM 的 flag 送到 scoreboard 統一表單:

```http
POST /scoreboard/?capture=the_flag
Content-Type: application/x-www-form-urlencoded

name=<用戶名>&flag=FLAG{...}
```

成功會 redirect 回 scoreboard, 用戶總分跟 Events 列表會更新.
