# PHM #49 Reversing — 2018-rev

| 項目 | 值 |
|:---|:---|
| 類別 | Reversing |
| 分數 | 150 |

## 題目

> Happy New Year 2018! Can you execute this binary on the right time with the right argv?
>
> 檔案: [`/static/2018.rev`](https://ctf.hackme.quest/static/2018.rev)
> ELF 64-bit, statically linked, stripped (但保留 glibc assert 字串).

## 分析

### 第一層: 格式 assert

直接跑:

```
2018.rev: 2018.c:67: main: Assertion `argc == 2018 && argv[0][0] == 1 && envp[0][0] == 1' failed.
```

需要:
- `argc = 2018`
- `argv[0][0] = 1` (第一個 argv 開頭是 `\x01`)
- `envp[0][0] = 1`

用 `os.execve()` 一次性塞 2018 個 arg + 一個 env, 第一個以 `\x01` 開頭.

### 第二層: 時間 assert

跑過 argc 之後吐:

```
Bad timing, you should open this at 2018/1/1 00:00:00 (UTC) :(
```

main 做了:
1. `time(&t)` 拿當前時間
2. `gmtime(&t)` 轉成 struct tm 存在 `0x6ce2a0`
3. 連續檢查:
   - `[rbx+0x10] = 0x7600000000` → `tm_mon=0, tm_year=118` (year=1900+118=2018)
   - `[rbx+0x08] = 0x100000000` → `tm_hour=0, tm_mday=1`
   - `[rbx+0x00] = 0` → `tm_sec=0, tm_min=0`

全對才呼叫 `decrypt_flag()`.

### 第三層: 時間值被 decrypt 吃進去

patch 掉三個 compare 讓 flow 繼續, 吐出來是 **半糊** 的字串:

```
FLAG{Hap?K?Eew Y?!?2018, Keep H?dcng E?%?I Day!}
```

對照英文可以**猜出來** flag:

```
FLAG{Happy New Year 2018, Keep Hacking Every Day!}
```

送上去就 AC. 猜對是因為「Happy New Year」、「Keep Hacking Every Day」是很固定的英文片語, 可讀部分已經給出一半以上.

## 解法 (兩套)

### 省力版: patch 時間 compare → 吐糊字串 → 用英文猜

```python
# 把三個 compare 都 bypass
patches = [
    (0x6bf, b'\x74\x27', b'\xeb\x27'),   # je 0x4006e8 → jmp
    (0x6f6, b'\x75\xc9', b'\x90\x90'),   # jne → nop
    (0x6fc, b'\x75\xc3', b'\x90\x90'),
]
```

輸出半糊字串 → 用英文補成 `FLAG{Happy New Year 2018, Keep Hacking Every Day!}`.

### 正解: 真的做 fake time

因為 static-link, LD_PRELOAD 的 faketime 失效. 要:

- 直接 patch `time()` syscall wrapper (`virt 0x43eda0`) 返回 `0x5a497e00` (= 2018/1/1 UTC epoch)
- 或在 code cave 寫 struct tm 的 6 個 int 到 `0x6ce2a0`

兩者都要處理 glibc 內部 TZ 轉換, 很囉嗦. 省力版猜中就夠.
