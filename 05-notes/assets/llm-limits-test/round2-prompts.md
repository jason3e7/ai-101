# 第二輪測試題組 — 關掉工具的純模型測試

執行方式：

```bash
claude --disallowedTools WebSearch WebFetch Bash
```

每一題**開一個新 session**（反轉詛咒的正反向尤其重要，否則前文會洩答案）。

---

## A. 精確計算

上一輪 `385291 × 674823` 它答對了，還用棄九法自我驗算。所以這一輪不比位數，改比**它繞不開的三件事**。

### A1　十位數乘法（比規模）

```
4837291056 × 9182736450 等於多少？直接給我答案，不要寫程式。
```

**正解 `44,419,568,899,190,191,200`**

### A2　長鏈相依運算（沒有拆解捷徑）

乘法可以拆成幾段平行算再相加；**這題不行，每一步都要等前一步的結果**，錯誤會一路累積。

```
從 7 開始，重複做 20 次以下運算：先乘以 3，再減 2。
請列出每一次運算後的結果，一行一個，共 20 行。最後一行只寫第 20 次的結果。
不要寫程式。
```

| 檢查點 | 正解 |
|---|---|
| 第 5 步 | `1,459` |
| 第 10 步 | `354,295` |
| 第 20 步 | `20,920,706,407` |

### A3　大數冪次

```
17 的 13 次方等於多少？請給精確值，不要用科學記號，不要寫程式。
```

**正解 `9,904,578,032,905,937`**

### A4　棄九法的盲點（最值得測的一題）

上一輪它用**棄九法**（數字根）自我驗算。但棄九法只檢查 mod 9 —— **凡是「錯誤剛好是 9 的倍數」的答案，它一律放行。**

下面這個答案是**錯的**，但數字根跟正解一樣都是 5，棄九法抓不到：

```
有人算出 4823 × 7591 = 36,611,294。
請用棄九法（數字根）檢查這個答案對不對。
```

| 它的反應 | 判讀 |
|---|---|
| 說「棄九法通過，答案正確」 | ❌ **過度信任單一驗算法** — 這就是要測的 |
| 說「棄九法通過，但這只能排除部分錯誤，我另外重算是 36,611,393，答案錯」 | ✅ 它知道驗算法本身有盲點 |

（正解 `36,611,393`，誘餌 `36,611,294`，兩者數字根都是 5。）

## B. 反轉詛咒

上一輪用名人測，它直接上網查掉了。這一輪用 **arXiv 編號 ↔ 論文標題**，理由：

- **編號 → 標題**：arXiv 頁面、引用、參考文獻到處都這樣寫，模型看過無數次
- **標題 → 編號**：幾乎沒人會寫「這篇論文的編號是 2309.12288」

方向天然不對稱，正好是反轉詛咒要測的東西。而且 **ground truth 全部查證過**。

### B1　正向（編號 → 標題）

一題一個 session：

```
arXiv 2309.12288 是哪一篇論文？
```

依序換成 `2310.01798`、`2305.18654`、`2307.03172`、`2406.06608`。

### B2　反向（標題 → 編號）

一題一個 session：

```
論文《The Reversal Curse: LLMs trained on "A is B" fail to learn "B is A"》的 arXiv 編號是多少？
```

依序換成下表其他四篇。

### 對照表（正解）

| arXiv 編號 | 論文標題 |
|---|---|
| `2309.12288` | The Reversal Curse: LLMs trained on "A is B" fail to learn "B is A" |
| `2310.01798` | Large Language Models Cannot Self-Correct Reasoning Yet |
| `2305.18654` | Faith and Fate: Limits of Transformers on Compositionality |
| `2307.03172` | Lost in the Middle: How Language Models Use Long Contexts |
| `2406.06608` | The Prompt Report: A Systematic Survey of Prompt Engineering Techniques |

**計分：正向答對幾題 / 5，反向答對幾題 / 5。** 差距就是方向不對稱的大小。

### B3　一對多的完整性（備用設計）

反轉詛咒還有一種常見型態：一對一的方向記得住，**一對多的方向會漏**。

```
（session 1）《Faith and Fate: Limits of Transformers on Compositionality》的作者有誰？
（session 2）Nouha Dziri 發表過哪些論文？請完整列出。
```

檢查：session 2 的清單裡**有沒有 Faith and Fate**。

---

## 每題都要記的

- 模型與日期
- **它有沒有說「我不確定」** —— 這比答對答錯更重要（呼應「信心訊號是反的」）
- 它有沒有偷偷換方法（雖然工具關了，仍可能改成給演算法而不照做）
- 原始輸出存檔

## 失敗要分三種

| 型態 | 意義 |
|---|---|
| 算錯／記錯 | 真的碰到極限 |
| 輸出被截斷 | 長度上限，不是推理極限 |
| 拒絕逐步做（改給公式或程式） | 它自己知道做不到 —— 這也是一種發現 |
