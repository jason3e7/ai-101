# JT Doc Tools：自架文件處理平台（36 工具 + 本地 AI）

> [!info]
> 官網：[jasoncheng7115.github.io/jt-doc-tools](https://jasoncheng7115.github.io/jt-doc-tools/)
> **一句話：** 36 個文件處理工具（PDF、Office、OCR、去識別化等），全部跑在自己伺服器，可接本地 LLM 加強功能，原始碼 Apache 2.0 完全公開。

---

## 是什麼

**JT Doc Tools** 是一個自架式文件處理平台，
解決的問題是：法律、財務、HR、政府單位有大量敏感文件需要處理（壓縮、轉換、去識別化、OCR……），
但用雲端服務（Smallpdf、iLovePDF 等）就等於把資料送出去。

JT Doc Tools 把這些功能搬回自己的伺服器，
**所有檔案只在你的機器上處理，資料不出去。**

> [!tip] 授權
> Apache 2.0，免費使用，無付費方案，36 個工具全開放。

---

## 系統需求

| 項目 | 最低 | 建議 |
|---|---|---|
| RAM | 2 GB | 4 GB+ |
| 磁碟 | 3 GB | — |
| 架構 | x86_64 或 ARM64 | — |
| 系統 | Linux / macOS / Windows | — |

單指令安裝，自動偵測相依套件。Python-based，SQLite 後端。

## 六大分類 × 36 工具

### 填寫與蓋章（3 個）

| 工具 | 功能 |
|---|---|
| 表單自動填入 | 偵測 PDF/Word/Excel/ODF 表單欄位，批次填入公司資料 |
| 蓋章與簽名 | 拖放放置印章、簽名、Logo，支援批次處理 |
| 浮水印 | 文字或圖片浮水印，可調透明度、角度、位置 |

### 檔案編輯（6 個）

| 工具 | 功能 |
|---|---|
| PDF 編輯器 | 覆蓋文字、圖片、形狀、標注 |
| PDF 壓縮 | 三段預設或自訂 DPI 與字型子集化 |
| 多頁合併（N-up）| 2/4/6/8/9/16 頁合一 |
| 合併 / 分割 | 基本 PDF 頁面操作 |
| 頁面旋轉與整理 | 重排、旋轉、加頁碼 |
| 扁平化標注 | 把批注燒入內容，保留表單欄位 |

### 內容處理（10 個）

| 工具 | 功能 |
|---|---|
| 文字擷取 | 輸出 TXT / Markdown / Word / ODT，可接 LLM 重排段落 |
| 圖片擷取 | 自動去重複，ZIP 下載 |
| 附件擷取 | 還原 PDF 內嵌檔案 |
| 字數統計 | 字元/段落/句子統計，圖表 + CSV/JSON/Markdown 匯出 |
| 批注整理 | 擷取標注，產生報告或待辦清單 |
| 逐句翻譯 | 本地 LLM，並排比對，可設法律/醫療/技術領域提示 |
| OCR 文字辨識 | 雙引擎（EasyOCR + Tesseract），可接 LLM 修正錯字 |
| 清單處理 | 排序、去重複、篩選、轉換文字/CSV/Excel |
| 電子發票處理 | 掃描台灣發票 QR Code，自動查詢商家資訊與會計科目 |
| 統編查詢 | 8 碼統編或公司名稱反查，批次匯出 |

### 格式轉換（4 個）

| 工具 | 功能 |
|---|---|
| 文件轉 PDF | 批次轉換 Office / ODF |
| 文件轉圖片 | 頁面轉 PNG，5 個 DPI 等級（100 草稿 ~ 400 印刷）|
| 圖片轉 PDF | 排列、旋轉、刪頁，自訂頁面尺寸 |
| PDF 轉 Word/ODT（Beta）| 反向轉換，保留排版、表格、圖片 |

### 安全處理（6 個）

| 工具 | 功能 |
|---|---|
| 文件去識別化 | 偵測並遮蔽/刪除身分證、Email、銀行帳號等敏感欄位 |
| 文字去識別化 | 純文字版，針對 IT 資料（IP、主機名稱、API Token）|
| PDF 密碼保護 | AES-256 加密與權限控制 |
| 中繼資料移除 | 清除作者、標題、XMP、修訂紀錄 |
| 隱藏內容掃描 | 偵測 JavaScript、內嵌檔案、隱藏文字、外部連結 |
| 文件比對 | PDF / Office 並排差異比較 |

### 團隊 / 企業（3 個）

| 工具 | 功能 |
|---|---|
| 多領域認證 | 本地帳號 / LDAP / Active Directory，支援同名帳號 |
| RBAC 權限矩陣 | 6 個內建角色 + 自訂角色，可指定至使用者/群組/OU |
| 稽核日誌 + SIEM 整合 | 支援 syslog、CEF、GELF 格式，預設保留 90 天 |

## 本地 AI 整合（選用）

接上自己的 LLM 後，以下 11 個工具可解鎖 AI 加強選項：

```
支援：Ollama / vLLM / LM Studio / DGX Spark（任何 OpenAI API 相容端點）
```

| 工具 | AI 加強內容 |
|---|---|
| 逐句翻譯 | 依領域提示（法律/醫療/技術）翻譯 |
| 文字擷取 | 段落重排讓語意連貫 |
| 表單自動填入 | Vision 模型驗證欄位 |
| 文件去識別化 | 超越 regex 的語意偵測 |
| 文字去識別化 | 日誌/郵件的額外模式辨識 |
| 字數統計 | 自動摘要與關鍵字 |
| 批注整理 | 主題分群 |
| 文件比對 | 差異摘要說明 |
| OCR | 錯字修正（含幻覺防護） |
| 送件前審查 | 語意與視覺驗證 |
| 電子發票 | 會計科目自動分類 |

> [!tip] 資料不出去
> 所有 AI 推論都透過本地模型，不呼叫 OpenAI / Claude 等外部 API，
> 符合敏感文件的資料保護需求。
