## 課程核心主張

用 **Claude Code + Agent Skills** 把複雜的開發流程封裝成可重複使用的資產，
搭配 OpenSpec、Git Worktree、自動化測試、CI/CD，建立系統化的 AI 開發工作流。

---

## 三堂課內容

| 堂次 | 主題 | 重點 |
|---|---|---|
| **第一堂** | Agent Skills 基礎 | Rules vs. Commands vs. Skills 差異、安裝開源 Skills、建立第一個自訂 Skill |
| **第二堂** | 規格驅動開發 | OpenSpec Skill、用 CLAUDE.md 建立專案紀律、全端系統從零建起、迭代擴充功能 |
| **第三堂** | 自動化與多 Agent 並行 | 自動化測試、GitHub Actions CI/CD 整合、Git Worktree 多 Agent 並行開發、Code Review 流程 |
