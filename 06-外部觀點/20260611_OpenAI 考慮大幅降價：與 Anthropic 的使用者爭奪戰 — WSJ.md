# OpenAI 考慮大幅降價：與 Anthropic 的使用者爭奪戰

> [!info]
> 來源：[OpenAI Considers Drastic Price Cuts, Anticipating War for Users With Anthropic](https://www.wsj.com/tech/ai/openai-considers-drastic-price-cuts-anticipating-war-for-users-with-anthropic-9b8c178e)（WSJ，付費牆）
> 發表：2026-06-10
> **一句話：** OpenAI 正考慮大幅削減 token 定價，應對 Anthropic 估值超車與即將到來的 IPO 競爭，但兩家公司都還在虧錢的前提下打價格戰，風險極高。

---

## 事件背景

OpenAI 正在內部討論大幅削減 API token 定價，消息人士描述決策「仍在流動中」，尚無官方公告。

**直接觸發因素：**

1. **Anthropic 估值超車：** 2026-05-28 Anthropic 完成 Series H，估值達 **$9,650 億**，超過 OpenAI 的 **$8,520 億**（OpenAI 估值設定於 2026-03）
2. **Claude Code 效應：** Anthropic 在推出 Claude Code 後，run-rate 估值短暫超過 OpenAI
3. **IPO 競賽：** Anthropic 已秘密提交 IPO 申請；OpenAI 約於 2026-06-09–10 提交，Sam Altman 告知員工計畫一年內上市
4. **企業端反彈：** 大企業開始限縮 AI 用量（見相關筆記），Sam Altman 本人也承認「AI 高使用成本已成為企業主管的重大問題」

---

## 競爭格局

| 項目 | OpenAI | Anthropic |
|---|---|---|
| 估值（2026-06）| $8,520 億 | $9,650 億 |
| IPO 狀態 | 已秘密提交（~2026-06-09）| 已秘密提交（更早）|
| 預計盈利年份 | 2030 | 2028 |
| 現金燒耗 | 約 Anthropic 的 14 倍 | 較低 |

---

## 降價的結構性矛盾

兩家公司目前都在嚴重虧損。2026 年兩家合計在算力、訓練和營運上的估計支出約 **$650 億**。

打價格戰意味著：
- 在虧損的基礎上再壓縮毛利
- IPO 前的財務表現更難看
- 若只靠降價競爭而非能力差異，等於默認產品同質化

> [!warning]
> 市場領導者若主要以價格競爭，通常是產品差異化不足的訊號。

---

## Google 的壓力

Google 同期也在對 AI 服務降價，形成三方擠壓——OpenAI 和 Anthropic 都不只是在互相競爭，也在回應 Google 的定價動作。
