> 核心原則：**有清楚概念，又能快速上手。**

每一份筆記都確保你讀完能做到兩件事：

2. **快速上手** — 能立刻照著做，不需要再查其他資料

## 從這裡開始

不確定從哪讀？依你的目標挑一條路：

| 我想⋯ | 建議閱讀順序 |
|---|---|
| **理解基本名詞** | 核心概念 → 實用技巧與最佳實踐 |
| **開始用 Claude Code** | 核心概念 → Claude Code 生態系 → 實用技巧 |
| **學 2026 最關鍵技能** | Context Engineering → Harness Engineering |
| **跑本地模型（離線、隱私）** | Ollama 指令教學 → 輕量模型推薦 → Gemma 本地模型 |
| **架自己的 AI Agent** | OpenClaw 或 Hermes Agent |
| **挑最划算的 AI 模型** | 模型費用與效果比較 |
